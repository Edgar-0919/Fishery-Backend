# 饲料与投喂

## 鳜鱼食性特点

- 鳜鱼是典型的肉食性鱼类，终生以活鱼为食
- 野生环境下以小型鱼类、虾类为主
- 养殖条件下完全依赖投喂活饵料鱼
- 不摄食人工配合饲料（目前驯食成功率极低）
- 摄食方式是伏击式：隐蔽等待→突然出击→吞食

## 饵料鱼选择

### 理想饵料鱼特征
- 体型细长、纺锤形（便于鳜鱼吞食）
- 鳞片细小或无鳞（减少消化负担）
- 游泳能力适中（太慢鳜鱼不感兴趣，太快追不上）
- 耐低氧能力强（适应养殖环境）

### 推荐品种
1. **鲮鱼**（首选）：
   - 体型细长，鳞片细小，易消化
   - 生长快，繁殖力强，南方地区可自繁自养
   - 耐低氧能力较弱，需注意运输存活率

2. **鲫鱼**：
   - 适应性强，耐低氧，存活率高
   - 体型略高，较大个体不易被吞食
   - 适合北方养殖

3. **鲤鱼**：
   - 生长快，产量高
   - 鳞片较大较硬，消化稍差
   - 建议使用小规格（夏花）鲤鱼

4. **草鱼夏花**：
   - 体型细长，适合较大规格鳜鱼
   - 成本较低，容易获取

### 不推荐品种
- 罗非鱼：鳍条硬刺多，可能刺伤鳜鱼食道
- 麦穗鱼：体型过小，营养价值低
- 泥鳅：难以捕捉，钻泥习性

## 饵料鱼规格

| 鳜鱼规格 | 饵料鱼规格 | 饵料鱼体长 |
|---------|-----------|-----------|
| 3-5cm | 水花-1cm | 3-10mm |
| 5-10cm | 1-3cm | 15-30mm |
| 10-20cm | 3-7cm | 30-70mm |
| 20-30cm | 7-12cm | 70-120mm |
| >30cm | 10-15cm | 100-150mm |

## 投喂策略

### 投喂频率
| 水温 | 投喂间隔 | 说明 |
|------|---------|------|
| >28℃ | 3天 | 摄食旺盛，代谢快 |
| 22-28℃ | 3-5天 | 最佳生长温度 |
| 15-22℃ | 5-7天 | 摄食减少 |
| <15℃ | 7-10天或不投 | 几乎停止摄食 |

### 投喂量
- 保持池中饵料鱼数量为鳜鱼数量的10-15倍
- 每次投喂后观察3天，饵料鱼消耗超过70%时补充
- 日投喂量估算：鳜鱼总重量 × 5-8%（水温>25℃）

### 饵料鱼消毒
- 投喂前必须消毒
- 方法：3%食盐水浸浴5-10分钟
- 或用聚维酮碘5ppm浸浴10分钟
- 消毒后清水冲洗再投入鳜鱼池

## 投喂注意事项

1. 不投喂病鱼、死鱼、变质的饵料鱼
2. 饵料鱼规格应符合鳜鱼口裂大小
3. 饵料鱼投喂前停食1天（减少排泄物污染水质）
4. 高温季节适当增加投喂量
5. 暴雨、台风前后减少投喂
6. 用药期间暂停投喂或减量投喂
